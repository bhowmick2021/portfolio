My Journey

Technical decisions, implementation and operation

  1. 01 / DECIDE

    Architecture decisions

    Choosing where data lives and how it moves: a secondary TimescaleDB database for very heavy Tableau extracts instead of repeated BigQuery reads, one shared FastAPI backend for the governance tools, and a governed cutover plan for the BigQuery migration. TimescaleDB case →

  2. 02 / BUILD

    Hands-on implementation

    Python, SQL, FastAPI, Docker and Airflow: the daily BigQuery-to-TimescaleDB sync with atomic transactions and Slack alerting, plus Query Doctor and Atlas. Shared backend and tools →

  3. 03 / FIX

    Troubleshooting

    On the first live run of the rebuilt sync I diagnosed two production bugs: a string-escaping bug that silently disabled incremental decompression, and a null-value validation bug that starved the job queue. Both fixed. Read the case →

  4. 04 / AUTOMATE

    Automation

    Scheduled governance scans and cost-visibility tooling today; earlier, BigQuery-metadata alerting routed to owners with n8n (historical). Library: alert automation →

  5. 05 / VALIDATE

    Validated AI-assisted delivery

    GPT frames and plans, Claude builds and debugs, and I review, validate in staging, deploy and operate, with rollback checkpoints on every release. AI-assisted case →
